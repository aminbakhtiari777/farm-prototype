# audio/

- `sfx/sheep_baa_1..3.ogg` – sheep bleats (played by `Sheep/BleatPlayer`, random variant + pitch)
- `sfx/footstep_grass_1..4.ogg` – footsteps (played by `Player/Footsteps` every stride)
- `ambience/meadow_day_loop.ogg` – looping wind/birds bed (`Main/Ambience`, loop set in the import settings; quieter at night)
